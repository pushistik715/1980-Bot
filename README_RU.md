# Анонимный Telegram-бот — стартовый проект

## Важно перед запуском
Это стартовая версия для тестирования, а не готовая к коммерческому запуску система.
Перед публичным запуском проверьте доступы, резервное копирование, хранение персональных данных,
правила обработки сообщений и восстановление базы после перезапуска хостинга.

## Что умеет
- Принимать личные сообщения и медиа через Telegram Bot API.
- Копировать сообщения в закрытую группу без стандартной подписи пересылки.
- Позволять модераторам отвечать на сообщение в группе через Reply.
- Показывать сведения об отправителе только OWNER_ID.
- Блокировать и разблокировать пользователей командами владельца.
- Показывать статистику.

## Переменные окружения
- BOT_TOKEN — токен от BotFather (никогда не публикуйте его).
- OWNER_ID — Telegram ID владельца.
- GROUP_ID — ID закрытой группы. Временно поставьте 0, чтобы узнать ID.
- MODERATOR_IDS — ID модераторов через запятую, без пробелов необязательно.
- DB_PATH — путь к базе данных на постоянном диске.

## Получение ID группы
1. Установите GROUP_ID=0.
2. Запустите бота.
3. В закрытой группе отправьте `/groupid`.
4. Владелец получит ID группы в ответе бота.
5. Укажите полученный ID в GROUP_ID и перезапустите бота.

Для команды /groupid бот должен получать команды в группе. При необходимости отключите Privacy Mode
через BotFather: /setprivacy -> выберите бота -> Disable. Для обычного ответа на сообщение бота
Privacy Mode, как правило, не требуется отключать.

## Локальный запуск
Python 3.11+:
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
```
Задайте переменные окружения из `.env.example` (переименуйте копию в `.env` и используйте
загрузчик dotenv, если запускаете локально; либо задайте переменные в системе/хостинге).
Для удобства локального запуска можно добавить `python-dotenv` и `load_dotenv()`.

## Безопасность
- Не добавляйте `.env`, токен или файл базы данных в публичный GitHub-репозиторий.
- Используйте приватный репозиторий.
- Доступ к панели владельца проверяется по OWNER_ID.
- Только ID из MODERATOR_IDS могут отвечать в группе.
- Не предоставляйте модераторам доступ к хостингу, базе данных или журналам.
- Администраторы Telegram-группы могут видеть сообщения, скопированные ботом, но не должны иметь
  доступ к исходному ID отправителя через интерфейс бота.
- Владельцу следует защищать свой Telegram-аккаунт двухэтапной аутентификацией.

## Ограничения этой версии
- Владелец может увидеть отправителя только по кнопке на скопированном сообщении.
- Ответ модератора доставляется копированием его сообщения пользователю.
- Не реализованы редактирование/удаление истории, поиск, очередь модерации и расширенный аудит.
- SQLite требует постоянного диска. Не используйте эфемерный файловый диск на хостинге.
- Telegram Bot API имеет ограничения на размер и типы медиа.
